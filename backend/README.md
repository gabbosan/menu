Restaurado: backend mínimo

Instruções rápidas para rodar localmente:

1. Entrar na pasta do backend:

   cd backend

2. Instalar dependências:

   npm install

3. Criar arquivo `.env` com a variável `MONGODB_URI` apontando para seu Atlas ou Mongo local.

4. Rodar em modo desenvolvimento:

   npm run dev

Observação: este é um backend mínimo criado para recuperar o ambiente rapidamente. Substitua ou recomponha arquivos perdidos a partir do repositório remoto quando possível.
